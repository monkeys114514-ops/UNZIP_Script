# Termux 一键解压脚本

一个给 **不会解压、不会用 MT 管理器、不会敲命令** 的人准备的傻瓜式解压工具。

在 Termux 里运行一个脚本，按提示输入数字，就能把 7z / zip / rar / tar / gz 等压缩包解压到手机 Download 目录，**全程不需要 Root，不需要 ADB**。

## 使用前提

1. 手机上装好 **Termux** 以及 **MT 文件管理器**（若没有安装，请见 [下载链接](#下载链接) 部分）
2. 首次运行脚本时，Termux 会弹窗申请存储权限，**点“允许”**

## 快速开始

### 第一步：把脚本下载到手机  
首先通过仓库底部的Releases板块下载脚本，具体视频操作可见 [录屏教程](#录屏教程) 板块的“如何通过浏览器下载脚本视频” ，下载完成后
请确保脚本是放在下载目录的（即 `/sdcard/Download` 目录）

> **不过一般通过浏览器下载的文件都会在下载目录，所以无需担心**

### 第二步：在 Termux 里运行

打开 Termux，复制粘贴下面这行，回车：

```bash
cd /sdcard/Download && bash unzip.sh
```

> 长按终端 → Paste 可以粘贴。

### 第三步：根据脚本提示操作

脚本会依次问你：

1. **压缩包从哪来？**
    - 输入 `1`：浏览器下载的，在 `Download`
    - 输入 `2`：QQ 保存的，在 `Download/QQ`
    - 输入 `q`：退出

2. **压缩包叫什么？**
    - 支持模糊匹配，比如压缩包名是 `我的资源v2.7z`，你输入 `我的资源` 就行
    - 脚本会搜出匹配的包，问你 `y/n`
    - 如果匹配到多个，会列出来让你输编号
    - 如果一个都没匹配到，会把当前目录所有压缩包列出来让你选编号

3. **确认后自动解压**
    - 解压完成会告诉你文件在哪，一般是：
      ```
      /sdcard/Download/包名_extracted_随机数/
      ```
    - 解压后的文件可通过 MT 文件管理器查看

### 补注：QQ 文件怎么放到 Download/QQ

QQ 从群文件下载的压缩包，默认藏在很深的应用私有目录里，普通脚本访问不到。

**最简单的办法**：在 QQ 里找到那个压缩包 → 右上角三个点 → 点 **保存到手机** → QQ 会自动把它复制到：

```
/sdcard/Download/QQ/
```

具体操作可看仓库videos文件夹里的录屏：

- `videos/qq_save_to_download.mp4`

> 如果 `Download/QQ` 目录不存在，脚本第一次运行选项 2 时会自动创建，不用你手动建。

## 常见问题

### 1. 提示 `7zip 自动安装失败`

可把脚本打印出来的报错**完整复制**或**截图**交给 AI，或手动执行：

```bash
pkg install 7zip
```

看具体报错。

### 2. 解压失败，提示“文件损坏 / 密码错误 / 分卷不全”

- 确认压缩包下载完整
- 如果是分卷包，确认 `.001` `.002` `.003` … **全部在同一个目录**，并且文件名正确
  比如，一个正常的分卷压缩应该会含有多个名字相似的压缩包，具体可见 [分卷压缩](#分卷压缩)

### 3. 选 QQ 目录后提示“无法创建目录”

说明 Termux 没有存储权限。重新运行脚本，弹窗时点“允许”；或手动粘贴并执行：

```bash
termux-setup-storage
```

### 4. 安卓 11 以上能直接访问 QQ 私有目录吗？

**不能**，除非用 Shizuku / Root 授权。所以本脚本**不直接读 QQ 私有目录**，而是让你在 QQ 里点“保存到手机”，把文件复制到 `Download/QQ`，脚本再从这个公开目录解压。

### 5. 解压出来的文件夹名后面为什么有随机数？

防止多次解压同一个包时互相覆盖。比如：

```
我的资源_extracted_12345/
我的资源_extracted_67890/
```

内容都是一样的，随便进哪个都行。

### 6. 为什么不用 MT 管理器

MT 管理器虽然很强，但对完全不懂的人，光是“找到文件 → 长按 → 解压 → 选目录 → 确认”就能卡住。

这个脚本把流程压缩成：

> 把包放好 → 运行脚本 → 按提示输数字

少一步是一步。

## 分卷压缩

分卷压缩（Multi-part archive）是将一个大型文件或文件夹分割成多个较小体积的压缩包的技术，主要用于突破存储介质容量限制或网络传输的单文件大小限制。**这里以 7z 格式为例进行说明。**

### 7z 分卷文件的外观与命名规律

以 7z 格式进行分卷压缩后，你看到的不是单个压缩包，而是一组按顺序编号的文件。例如，一个分卷压缩的资源的分卷文件名通常如下：

```
<压缩包名>.7z.001
<压缩包名>.7z.002
<压缩包名>.7z.003
...
```

**命名规律**：我们可以把它看成三个部分

| 第一部分 | 第二部分 | 第三部分 |
| :--- | :--- | :--- |
| <压缩包名> | 7z（压缩格式） | 001（分卷编号） |

当你要解压一个分卷压缩包时，应当保证：

1. 分卷齐全
2. 确保所有分卷的 **“第一部分”**（即压缩包名）、**“第二部分”**（即压缩格式）完全相同，**“第三部分”**（即分卷编号）**无缺**（比如你一共有三个分卷，那么分卷编号应该有 001、002、003）

总结来说：所有分卷的基础名称相同，后缀为 `.7z`，末尾追加三位数字编号，从 `001` 开始递增（`.001`、`.002`、`.003`……）。**编号最小的 `.7z.001` 是起始文件**，它是整个分卷组的入口，所有后续分卷都依附于它。

### 为保证解压不出错，需要注意以下问题

#### 1. 分卷文件必须完整且齐全

分卷组是一个整体，**缺一卷不可**。任何一个分卷文件丢失、下载不完整或损坏，都会导致解压失败，常见报错包括 `Cannot open compressed file`、`CRC error` 或 `No such file or directory`。解压前请确认 `.001` 到最后一卷均存在。

#### 2. 所有分卷必须放在同一目录下

压缩软件依赖同一目录下的分卷文件自动串联读取。分卷分散在不同文件夹中，软件将无法定位后续分卷，解压会中断。

#### 3. 不要重命名分卷文件

分卷的命名格式（`.001`、`.002`……）是软件识别顺序的唯一依据。将 `.7z.001` 改为 `.part1` 或加入额外后缀，会导致软件无法识别，解压直接失败。

### 除了 7z，常见的分卷格式

| 格式 | 分卷命名示例 | 备注 |
| :--- | :--- | :--- |
| **RAR** | `data.part1.rar`、`data.part2.rar` | 起始文件为 `part1.rar` |
| **ZIP（新式）** | `data.zip.001`、`data.zip.002` | 与 7z 命名规律类似 |
| **ZIP（老式）** | `data.z01`、`data.z02`……`data.zip` | 起始文件为 `.zip`，`.z01`、`.z02` 为前置分卷 |
| **TAR（GNU 多卷）** | `archive.tar-aa`、`archive.tar-ab` | 通过 `tar -M` 创建，不支持压缩 |

这些格式的共性在于：均需保证所有分卷齐全且位于同一目录，并操作正确的起始文件方可成功解压。

## 支持的文件格式

**支持解压：**

- `.7z` / `.7z.001`（分卷）
- `.zip`
- `.rar`
- `.tar` / `.tar.gz` / `.tgz` / `.tar.bz2` / `.tar.xz`
- `.gz`

> `.rar` 的解压依赖 `7zip` 自带支持，个别特殊压缩方式可能失败，届时建议用 ZArchiver 或 MT 文件管理器。
